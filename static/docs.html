Enroll Owner

Use the camera page to add 3-5 face images for one owner.

GET/enroll

IoT Ping

Use this first from ESP32 or another IoT client to check the AI server connection.

curl http://localhost:8000/iot/ping

Web Verify

Use the browser camera to test the same face verification flow as the IoT device.

GET/verify

IoT Verify API

Send a camera frame from ESP32-CAM or another client and read only the action field.

curl -X POST http://localhost:8000/verify-face \
  -F "file=@test_images/anhtest1.jpg"

Response Rule

For the IoT side, open the door only when action is exactly OPEN.

{
  "action": "OPEN"
}
